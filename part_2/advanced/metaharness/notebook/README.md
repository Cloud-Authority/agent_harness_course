# Understanding a meta-harness: MemoRizz, read and run

`advanced_metaharness_memorizz.ipynb` reads MemoRizz's meta-harness from its source,
module by module, and runs it: a read-only task on Claude Code, a three-stage plan in
which pi plans, Codex implements behind an approval and Claude Code reviews, and a
comparison that puts one question to two agents. Memory, the run ledger and the approval
queue live in Oracle AI Database.

Needs Docker (Oracle AI Database Free), `ANTHROPIC_API_KEY`, and the coding agents: Claude
Code, Codex with its own login, and pi and Hermes from `part_2/harness_done_for_you/.tools`.

`MEMORIZZ_SRC` names the MemoRizz checkout to read (default `~/Desktop/memorizz/src`).
When it is unset or missing, the installed `memorizz` package is used instead.
